# TRADETracker

**Personal Cryptocurrency Market Intelligence Dashboard**

TRADETracker is a personal market research and analytics application developed with Python, SQLite, PowerShell, and HTML.

The application runs locally on Windows and collects financial market data from publicly available sources and APIs.

## Features

- Automated cryptocurrency market monitoring at 15-minute intervals
- Exchange capital flow analysis (Binance, OKX, Bybit, MEXC)
- Spot prices and futures open interest monitoring
- Cryptocurrency market capitalization and dominance indicators
- ETF inflow and outflow tracking for BTC, ETH, SOL, and XRP
- Historical data storage using SQLite
- Interactive analytical dashboard with charts and historical comparisons

## ETF Intelligence

The ETF Intelligence module monitors daily cryptocurrency ETF fund flows, historical trends, and available fund-level data.

Supported integrations include TFTC, CryptoETF.Today, and XOOMAR.
